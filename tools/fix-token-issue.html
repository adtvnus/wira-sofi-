🔧 Fix Token Issue

Resolve "Invalid token" error in admin pages

⚠️ Problem: You're getting "Database error (403): Invalid token" when saving settings.
🔍 Cause: Your browser has an expired authentication token cached.

🚀 Quick Fix (Recommended)

Click the button below to automatically clear your authentication cache:

🛠️ Manual Fix (Alternative)

If the quick fix doesn't work, follow these steps:

  1. Press F12 to open Developer Tools
  2. Go to Application tab
  3. Find Local Storage → http://localhost:5173
  4. Delete these keys:
    auth-token
    auth-user
  5. Close Developer Tools and refresh the page

🔐 After Clearing Cache

1. You'll be redirected to the login page
2. Login again with: admin / admin
3. All admin pages should work properly now
